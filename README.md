# AWS Builder Center Landing Page

Starter landing page for `aws.birendrasasmal.in`.

## Before launch
1. Replace `YOUR_BITLY_LINK_HERE` in `app/page.tsx` with the official Bitly registration link supplied for the program.
2. Connect the form submit handler to the chosen Google Sheets/Form backend.
3. Review SBCL/AWS brand and communication guidelines before publishing.
4. Add the Cloudflare DNS record for the `aws` subdomain and configure the deployment.

## Run locally
```bash
npm install
npm run dev
```
